Escanear lámina

Saca una llave gratis de la IA de Google (3 pasos) y el lector va a leer las fotos muchísimo mejor:

  1. Entra a aistudio.google.com/apikey con tu cuenta de Google.
  2. Toca "Create API key" (Crear clave). Es gratis.
  3. Copia la clave (empieza con AIza…) y pégala aquí abajo.
La clave queda solo en tu navegador, en este equipo. Nadie más la ve.

Nube y compartir

Para sincronizar en tiempo real y compartir con alguien, conecta tu proyecto gratis de Firebase (4 pasos):

  1. Entra a console.firebase.google.com y crea un proyecto.
  2. Menú Compilación → Firestore Database → Crear (modo de prueba).
  3. Menú Compilación → Authentication → Comenzar → Correo/contraseña → Activar.
  4. Engranaje ⚙ → Configuración del proyecto → en "Tus apps" crea una app Web (</>) y copia el bloque firebaseConfig.
Tus claves quedan solo en tu navegador. Súbela a internet (GitHub Pages) y agrega ese dominio en Firebase → Authentication → Settings → Dominios autorizados.
